# Disable VS Matchup Track from Playing

This feature makes it so that the track that plays during the VS. Screen (when loading into a match from the Smash Menu) is prevented from loading at all. This allows you to seamlessly listen to your track.

![type:video](<../img/The CSK Collection/disable_matchup.mp4>)

To enable this feature, create a file called `mods:/flags/disable_matchup.flag`.
It's recommended that when using this feature, you don't use ["Disable Music Autoplay on Track Selection"](<Disable Music Autoplay on Track Selection.md>) feature.
