# Show Music Track on Pause

**Important Note: By default, the Music Track info overlays with the "PAUSE" text. The CSK Collection comes with a `info_melee/layout.arc` modified to account for this, and it's recommended that you use this if you plan on using this feature. If this conflicts with another mod that also modifies this file, then you can delete the one that comes with the CSK Collection and manually move the track container down.**

This feature will show what track is currently playing when you pause during a match.

![Showing the track when game is paused](<../img/The CSK Collection/show_music_track_on_pause.gif#center>)

To enable this feature, create a file called `mods:/flags/show_track_on_pause.flag`.

It's recommended to use the pre-made `Show Music Track on Pause` folder that comes with the CSK Collection.
