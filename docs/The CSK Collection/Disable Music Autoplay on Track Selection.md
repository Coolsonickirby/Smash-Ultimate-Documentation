# Disable Music Autoplay on Track Selection

After update 8.1.0, when picking a track (either through the album selector or normal playlist), the music will automatically start playing. This feature reverts that.

![type:video](../img/Walkthroughs/Disabling%20Auto-Play%20on%20Playlist%20Music%20Selection/success.mp4)

To enable this feature, create a file called `mods:/flags/disable_autoplay.flag`.
It's recommended that when using this feature, you don't use ["Disable VS Matchup Track from Playing"](<Disable VS Matchup Track from Playing.md>) feature.
