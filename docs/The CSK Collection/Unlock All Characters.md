# Unlock All Characters

This feature makes it so that all characters will be avaliable to be chosen in the Smash Menu, however, you will still get the unlock challenge for fighters.

To enable this feature, create a file called `mods:/flags/unlock_all_fighters.flag`.

If you want the fighters to be unlocked properly, then its better to use [this plugin](https://github.com/asimon-1/auto-char-unlock/releases/latest) made by [asimon-1/CPU_1](https://github.com/asimon-1). This plugin runs by itself and unlocks all the characters legitimately for you. Make sure to read its [README](https://github.com/asimon-1/auto-char-unlock#ssbu-auto-unlock-characters) properly before using it.
