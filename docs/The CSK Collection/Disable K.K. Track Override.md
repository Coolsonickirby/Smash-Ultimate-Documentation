# Disable K.K. Track Override

Normally, on Saturday evening from 8PM to 12AM, K.K. Slider forces himself into Smashville and takes over whatever track was selected. This feature disables K.K. Slider from taking over and playing his own music.

![type:video](<../img/The CSK Collection/disable_kk_override.mp4>)

To enable this feature, create a file called `mods:/flags/disable_kk_override.flag`.
