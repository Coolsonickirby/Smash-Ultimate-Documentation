# Restore Announcer First, Fighter Name Last for Victory ("The Winner Is...")

This feature restores the announcer starting with "The Winner Is..." followed by the winner's name.

![type:video](<../img/The CSK Collection/winner_is.mp4>)

To enable this feature, create a file called `mods:/flags/the_winner_is.flag`.

It's recommended to use the pre-made `Restore The Winner Is` folder that comes with the CSK Collection.
