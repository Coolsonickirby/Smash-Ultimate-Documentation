# One Slot Series

**Warning: This feature is very unstable and will crash the game if it's not used in Smash mode 1v1 only.**

To use the One Slot Series feature, create a flag called `mods:/flags/enable_one_slot_series.flag`, then add a new key to the character database entry in `ui_chara_db.prc` with the type of `Hash40` and a key of `ui_series_id_cXX` (replace `cXX` with the color you want to set), then set the value to be the `ui_series_id` you want to set it to.
