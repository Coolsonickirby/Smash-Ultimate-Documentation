# What is the CSK Collection

**Latest Version: 6.0.0 (13.0.5)**

This is a plugin containing multiple features, some that activate automatically and others that rely on flags. It also contains API calls that other plugins can use.

**Notice: When `mods:/` is used anywhere in the following pages, this refers to any mod folder in `sd:/ultimate/mods`. It can either be a mod folder you created yourself or a mod that already exists within it.**
