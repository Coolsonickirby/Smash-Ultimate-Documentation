# All Songs in Playlist

This feature puts all songs in the BGM Database into any specified playlists.

To enable this feature, create a file called `mods:/flags/all_songs_in_one_playlist.flag`. After its created, open it up in any text editor, then add all the playlists you want all tracks to be added to.
