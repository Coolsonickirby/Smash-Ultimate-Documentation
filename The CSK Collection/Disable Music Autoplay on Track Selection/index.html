    Disable Music Autoplay on Track Selection

    After update 8.1.0, when picking a track (either through the album selector or normal playlist), the music will automatically start playing. This feature reverts that.

    To enable this feature, create a file called mods:/flags/disable_autoplay.flag. It's recommended that when using this feature, you don't use "Disable VS Matchup Track from Playing" feature.
