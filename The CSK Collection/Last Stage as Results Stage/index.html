    Last Stage as Results Stage

    Warning: This feature doesn't run the stage setup code, so any dynamic assets (controlled by code) used by the stage will spawn in the center. If playing on the FD form, the BF platforms will also show up.

    This feature changes the results stage that gets loaded with the last stage that was loaded.

    To enable this feature, create a file called mods:/flags/use_last_stage_for_results.flag. You can open up this file in a text editor and add stages that should be blacklisted from loading. For example, the flag containing the following:

    stage/75m/normal
stage/fe_arena/normal
stage/animal_village/battle

    would make it so that 75m (Normal), Arena Ferox (Normal), and Smashville (BF and FD forms) load the normal results stage instead.
