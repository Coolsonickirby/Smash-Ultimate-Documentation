    Enable Album Selector on All Stages

    To enable this feature, create a file called mods:/flags/enable_album_selector_on_all_stages.flag in your mod folder. You can then open the file in any text editor and add any ui_stage_id you don't want to have the album enabled for in it to make them use the playlist instead. For example,

    ui_stage_dk_lodge
ui_stage_kirby_halberd
ui_stage_nintendogs

    would make it so that Jungle Japes, Halberd, and Living Room use whatever playlist they had associated with them, while all other stages open the album selector instead.
